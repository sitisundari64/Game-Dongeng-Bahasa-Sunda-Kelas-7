📖 DIAJAR DONGÉNG SUNDA

Materi ringkes pikeun murid Kelas VII SMP

1. Harti & Ciri Dongéng

Dongéng nyaéta carita rékaan (fiksi) anu sumebar sacara lisan, diwariskeun turun-tumurun, sarta mindeng ngandung unsur pamohalan (hal anu teu asup ku akal).

  • Carita rékaan / teu bener-bener kajadian.
  • Ngandung unsur pamohalan (ajaib/gaib).
  • Miboga amanat atawa piwuruk keur nu maca.
  • Sumebar sacara lisan (anonim).

2. Rupa-rupa Dongéng

  • • Sasakala: Nyaritakeun asal-usul tempat/barang (upami: Tangkuban Parahu).
  • • Fabel: Nyaritakeun sasatoan nu bisa nyarita kawas manusa (upami: Sakadang Kuya & Monyet).
  • • Mite: Dongéng nu patali jeung hal gaib/kapercayaan (upami: Nyi Roro Kidul).
  • • Sage: Dongéng kapahlawanan / babad (upami: Prabu Siliwangi).
  • • Parabel: Dongéng bodor / keur ngahibur (upami: Si Kabayan).

3. Unsur Intrinsik Dongéng

  • • Téma: Gagasan poko dina carita.
  • • Tokoh & Watek: Pelaku jeung sipatna (Protagonis / Antagonis).
  • • Galur: Runtuyan kajadian dina carita (Maju / Mundur).
  • • Latar: Tempat, waktu, jeung suasana kajadian.
  • • Amanat: Pesen / piwuruk moril anu rék ditepikeun.

Pituduh Deploy ka GitHub Pages

Pikeun ngajalankeun ieu game dina internét sacara gratis tanpa backend/database:

1. Jieun Repository Anyar dina GitHub:

Buka github.com, login, tuluy klik New Repository (misalna: dongeng-sunda-game).

2. Upload File Game:

Simpen kode ieu salaku file index.html. Upload file index.html éta ka repository anu nembe dijieun.

3. Aktipkeun GitHub Pages:

  • Buka menu Settings dina repository anjeun.
  • Klik bagian Pages di bilah kénca.
  • Dina Build and deployment, pilih Branch: main / root.
  • Pencét Save. Tunggu 1-2 menit.
